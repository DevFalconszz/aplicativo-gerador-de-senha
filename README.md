# 🔐 Gerador de Senhas Fortes

Um aplicativo simples e funcional desenvolvido em **React Native** com **Expo** para gerar senhas seguras e manter um histórico local das senhas criadas.

## 🚀 Funcionalidades

- **Geração Instantânea:** Cria senhas fortes com 12 caracteres (letras maiúsculas, minúsculas, números e símbolos).
- **Histórico Local:** Lista as últimas senhas geradas logo abaixo do botão principal.
- **Limpeza de Dados:** Opção para limpar o histórico e resetar a tela.
- **Interface Simples:** Design limpo e intuitivo em português brasileiro.

## 🛠️ Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo (SDK 54)](https://expo.dev/)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

## 📦 Como Executar

### Pré-requisitos
- Node.js instalado.
- Aplicativo **Expo Go** instalado no seu celular ([Android](https://play.google.com/store/apps/details?id=host.exp.exponent) ou [iOS](https://apps.apple.com/app/expo-go/id982107779)).

### Passo a Passo

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Inicie o projeto:**
   ```bash
   npx expo start -c
   ```

3. **Abra no seu celular:**
   Escaneie o código QR que aparecerá no terminal usando a câmera do seu celular (iOS) ou o próprio app Expo Go (Android).

## 📄 Estrutura de Pastas

- `App.js`: Contém toda a lógica e estilização do aplicativo.
- `package.json`: Configurações de dependências e scripts.
- `app.json`: Configurações globais do Expo.
